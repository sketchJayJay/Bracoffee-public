# BRACOFFEE v1.5

## Ajuste principal desta versão
Compra e estoque agora são totalmente separados.

- Finalizar uma compra cria OC, contrato e financeiro.
- Compra futura não entra e não aparece como estoque físico.
- Venda direta não entra no estoque.
- Somente uma compra marcada como **Para estoque** pode ser puxada manualmente pela tela Estoque.
- O saldo do estoque considera apenas entradas físicas feitas pelo botão **Puxar OC para estoque**.
- Dados de lotes automáticos gerados por versões antigas são preservados no navegador, mas deixam de contar como estoque físico.
